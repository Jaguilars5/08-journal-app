# 🎓 Course Information

## About This Repository

This repository contains my implementation of the **Journal App**, a practical project developed during **Fernando Herrera's** React course. It's part of the React integration section with Firebase, Redux Toolkit, and Material-UI.

The project demonstrates the application of advanced React concepts in a real and functional application, including authentication, data persistence, global state management, and file uploads.
